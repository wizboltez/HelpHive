# 🐝 HelpHive — Smart Domestic Services Marketplace

> **Full-Stack Development Roadmap | 5 Weeks**

HelpHive is a web platform that connects **customers with domestic service providers** such as maids, cooks, babysitters, electricians, plumbers, etc.

### 👥 Team

* **Anannya → Entire Frontend**
* **Vaidehi + Anushka → Entire Backend**

# 🛠️ Tech Stack

### Frontend — Anannya

* React.js
* Tailwind CSS
* React Router
* Axios

### Backend — Vaidehi + Anushka

* Node.js
* Express.js
* MongoDB
* JWT
* bcrypt
